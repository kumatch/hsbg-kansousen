# season/

- `current.md` — **今**有効なシーズンのゲームシステム（そのシーズン特有の仕組み、出現する種族、禁止など）。常に最新の状態を表し、
  冒頭に「最終更新: <反映した最新のパッチ>」を書く。過去の状態は `patches/` を遡って復元する
- `pool/` — ミニオンプールのスナップショット。HDT のカードデータから `tools/pool.py` で生成する（使い方は `pool/README.md`）

更新の手順: パッチが来たら、先に `patches/` にファイルを作り、それから `current.md` を書き換える。
ミニオンの一覧や数値は書き写さない（カードデータやパッチの記録を参照する）。

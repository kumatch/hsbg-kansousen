# patches/

パッチ・ホットフィックス 1 つにつき 1 ファイル。ファイル名は `YYYY-MM-DD_<version>.md`（日付は適用日）。
新しいファイルは `_template.md` をコピーして作る。

- **適用日時**は分析が期間を区切るのに使う。分単位で分かれば書き、分からなければ日付 + `要確認`
- 変更表は 1 行 1 項目（1 枚のカードで攻撃力と Tier が変わったら 2 行）
- 種別は公式ノートの区分（強化 / 弱体化 / 変更 / 追加 / 削除 / 復帰）をそのまま使う。独自の評価は書かない
- 一度コミットした内容を直すときは別コミット `fix: ...` にする（分析が差分で気づけるように）

# 知識庫の変更の記録

この知識庫（`knowledge/`）を変えたら、**末尾に 1 行足す**（git を使っていても書く）。
分析はこの記録で、前回の分析の後に知識庫の何が変わったかを知る（パッチで期間を分けたり、過去の結論を見直したりするため）。
規約は `CLAUDE.md` の「変更の記録」。

形式: `- YYYY-MM-DD HH:MM <タイムゾーン> <種類>: <何をしたか>（<変えたファイル>）`

| 種類 | 使うとき |
|---|---|
| `patch` | パッチ・ホットフィックスを記録した（`patches/` に足し、`season/current.md` を更新した） |
| `fix` | 既存の記述の誤りを直した（何を直したかを書く。分析はこれを見て過去の結論を見直す） |
| `season` / `basics` / `docs` | それ以外の追加や更新 |

例: `- 2026-11-12 21:40 JST patch: 37.2 を記録（patches/2026-11-12_37.2.md, season/current.md）`

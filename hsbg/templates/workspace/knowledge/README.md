# knowledge — ゲームの事実の資料庫

Hearthstone Battlegrounds（以下 BG）という**ゲームそのもの**についての事実を集める場所。分析はここを読んで、
カードの Tier・数値、パッチでの変更、シーズンの仕組みを推測せずに確かめる。**自分のプレイの結論は入れない**（それは `../analysis/` にある）。

最初は空。パッチノートやゲーム内の表示を AI に渡して、少しずつ育てる（規約は `CLAUDE.md`）。

| ディレクトリ | 中身 |
|---|---|
| `basics/` | 分析が前提にしているルールの解釈、用語集 |
| `season/` | 現シーズンのゲームシステム（`current.md`） |
| `patches/` | パッチ・ホットフィックスごとの変更（`YYYY-MM-DD_<version>.md`。1 パッチ 1 ファイル） |

## 分析との約束

分析（`hsbg-analysis` スキル）は次を前提にする。構成は自由に変えてよいが、これだけは守る。

- `patches/YYYY-MM-DD_<version>.md` のファイル名の日付と、ファイル中の「適用日時: YYYY-MM-DD HH:MM JST」。分析はゲームの開始時刻と比べて、どのパッチの下で遊んだかを決め、期間をパッチで区切る
- カード・仕組みの事実に「確認: <確かめたビルドやパッチ>」を付ける。後のパッチで変わったかもしれない事実を、分析が「未確認」として扱えるように
- git で管理する（ワークスペースのリポジトリでよい）。分析は読んだ時点のコミットを記録し、次の分析でそこからの変更（`git log` / `git diff`）を見る。
  記述の誤りを直すときは `fix: ...` のように分かるコミットにする（分析がそれを見て過去の結論を見直す）

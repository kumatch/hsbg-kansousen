# Claude デスクトップアプリで使う

hsbg-kansousen は、Claude デスクトップアプリに頼むだけで使い始められます。ターミナルを開いたり、コマンドを打ったりする必要はありません
（インストールも分析も、Claude がコマンドを実行します。あなたは内容を見て許可するだけです）。
ターミナルで Claude Code（CLI）を使うときは、README の「[Claude Code（CLI）を使う](../README.md#claude-codecliを使う)」を見てください。

## 用意するもの

| もの | 内容 |
|---|---|
| Windows 10 / 11 | 記録アプリと同じ PC |
| 記録アプリ [hsbg-kifu](https://github.com/kumatch/hsbg-kifu) | BG のゲームを記録します。入れ方は hsbg-kifu の README。何ゲームか遊んで記録があると、すぐに分析を試せます |
| Claude の有料プラン（Pro 以上） | アプリの「コード」タブ（Claude Code）を使うため |
| [Claude デスクトップアプリ](https://claude.ai/download) | Claude のアカウントでサインインしておく |

## はじめかた

1. **ワークスペースにする空のフォルダを作る**。エクスプローラーで、たとえば「ドキュメント」の中に `hsbg-workspace` という名前のフォルダを作ります。
   ここに、あなたの目標、分析の結果、ゲームの知識が溜まっていきます
2. **Claude デスクトップアプリで「コード」タブを開き、1 のフォルダを選ぶ**。
   作業するフォルダを選ぶところで 1 のフォルダを選び、環境は「ローカル」のままにします。
   「このフォルダを信頼しますか」と聞かれたら、信頼します（ワークスペースの設定が使えるようになります）
3. **次の文をそのままコピーして送る**

   > hsbg-kansousen を使い始めたい。https://github.com/kumatch/hsbg-kansousen/blob/main/docs/install.md の手順に従って、このフォルダにセットアップして

4. **Claude の説明を読んで、始めてよければそう答える**。Claude は、何を入れるのか（uv と hsbg）、このフォルダに何を作るのかを説明してから始めます。
   コマンドを実行するたびに許可を求められるので、内容を見て許可してください
5. **質問に答える**。記録のフォルダの確認、カード名の言語、あなたの目標（例: 「1 位を取るより 5〜8 位を減らしたい」）を聞かれます。
   答えにくい質問は飛ばしてかまいません。答えは `profile.md` にまとめられ、以後の分析で毎回読まれます
6. **最後にアプリを一度終了して、開き直す**（入れたツールが、次から見つかるようになります）

Claude が何をするかは、[install.md](install.md)（Claude が読む手順書）にすべて書いてあります。

## ふだんの使いかた

アプリの「コード」タブで、いつも**同じワークスペースのフォルダ**を選んでセッションを始め、ふつうの言葉で頼みます。

| こんなとき | 頼み方の例 |
|---|---|
| ゲームの後に | 「さっきのゲームを分析して」「今日 6 位だったゲームを見て」「T7 で Tier 4 に上げたのは早すぎた？」 |
| 何ゲームか遊んだら | 「前回の傾向分析から後のゲームの傾向を見て」「直近 30 ゲームの傾向を見て」 |
| 数字とグラフを眺めたい | 「ダッシュボードを開いて」（終わったら「ダッシュボードを止めて」） |
| 毎回確かめたい観点ができたら | 「2 連敗した直後に Tier を上げたターンの成績を、毎回の傾向分析で見たい。レンズにして」 |
| パッチが来たら | 「BG のパッチが来た。パッチノートはこれ: <URL>。knowledge に記録して」 |
| 目標が変わったら | 「目標を変えたい。〜」 |

### ダッシュボード

数字とグラフ（成績の推移、ヒーロー、種族、1 ゲームごとの盤面など）は、ダッシュボードで眺められます。アプリの中のブラウザに表示されます。

- 「ダッシュボードを開いて」と頼む。終わったら「ダッシュボードを止めて」
- 自分で起動するときは、ブラウザペイン（上部のアイコンの「Browser」、または Ctrl+Shift+B）のヘッダーにある **Dev servers** メニューから
  「hsbg dashboard」を起動・停止します（メニューは、そのセッションで何かメッセージを送った後に出ます）

ダッシュボードは自分の PC の中だけで動き、ゲームのログを読むだけです。

### 許可を求められるコマンド

記録や集計を読むだけのコマンド（`hsbg config` / `validate` / `summarize` / `stats` / `lens list`）は、ワークスペースの設定
（`.claude\settings.json`）で許可済みなので、聞かれずに動きます（最初にフォルダを信頼したときから）。
ファイルを書くコマンドや、それ以外のコマンドは、実行の前に許可を求められます。内容を見て、よければ許可してください。

分析の中身や、知識庫（knowledge）の育てかたは [README の「ワークスペースでの使いかた」](../README.md#ワークスペースでの使いかた) を見てください。
そこに出てくるコマンドは、Claude が実行するので覚えなくてかまいません。

## 更新

「hsbg を更新して」と頼みます。Claude が新しい版を入れ、ワークスペースのスキルも新しくします。
記録アプリ hsbg-kifu を新しくしたときも、hsbg を更新してください（新しい記録の項目を読めるようになります）。

## 困ったとき

| こんなとき | どうする |
|---|---|
| 「Git が必要です」と表示される | アプリを最新の版に更新してください（今の版は、ふつうの使い方では git を求めません） |
| 「hsbg が見つからない」と言われる | アプリを一度終了して、開き直してください |
| 記録が見つからないと言われる | 記録アプリ hsbg-kifu が起動しているか（タスクトレイの「BG」のアイコン）、記録の出力先を変えていないかを確かめてください |
| 許可を求められるのが多くて面倒 | 内容を確かめて「常に許可」を選ぶと、同じ種類のコマンドは次から聞かれません |
| Dev servers メニューに「hsbg dashboard」が無い | セッションで何かメッセージを送ってから、もう一度見てください。それでも無ければ「ダッシュボードを開いて」と頼むか、古いワークスペースなら「hsbg init . を実行して」と頼みます（足りないファイルだけが足されます） |
| 分析やワークスペースを消してしまうのが心配 | ときどきワークスペースのフォルダごと、別の場所にコピーしてください |
